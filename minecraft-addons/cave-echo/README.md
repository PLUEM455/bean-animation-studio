# Cave Echo Sounds (Minecraft Bedrock Addon)

ทำให้เสียงก้องตามขนาดพื้นที่ที่ผู้เล่นยืนอยู่ ใช้ได้ทุกที่ในโลก โดยเล่นเสียง vanilla ซ้ำแบบหน่วงเวลา ไม่ต้องมีไฟล์เสียงเพิ่ม

## ทำงานอย่างไร
- ทุก 10 tick จะยิง ray 14 ทิศรอบหัวผู้เล่นแต่ละคน วัดว่า "ปิดล้อมแค่ไหน" และ "ผนังห่างเฉลี่ยเท่าไร"
- ค่าที่วัดจะค่อย ๆ เปลี่ยน (smoothing) เสียงจึงไม่กระตุกเวลาเดินเข้าออก
- ผู้เล่นแต่ละคนได้ยินเสียงก้องตามพื้นที่ของตัวเอง

| พื้นที่ | เสียงก้อง |
|---|---|
| ทุ่งโล่ง | แทบไม่ได้ยิน |
| ห้องหรือบ้านเล็ก | ก้องสั้น 1-2 ครั้ง เบา เสียงแหลม |
| ป่า หุบเขา | ก้องปานกลาง |
| ถ้ำใหญ่ | ก้องยาวสูงสุด 5 ครั้ง ดัง เสียงทุ้ม |

## เสียงที่ก้อง
- ขุดหิน ตัดไม้ และทุบบล็อก (เสียงตามชนิดบล็อก)
- ผู้เล่นหรือ mob โดนตี (เสียงตีและเสียงร้องเจ็บ)
- จุดไฟด้วยไฟแช็กหรือลูกไฟ

ค่าตั้งค่าอยู่บนสุดของ `behavior_pack/scripts/main.js` สูตรเสียงอยู่ในฟังก์ชัน `echoTaps`

## ข้อจำกัดของเกม
- ไม่มี reverb จริง เป็นการเล่นเสียงซ้ำแบบหน่วงเวลา และเสียงเดิมยังดังซ้อนอยู่
- เสียงที่ mob ร้องเองแบบสุ่มดักไม่ได้ ก้องเฉพาะตอนโดนตี
- การวัดพื้นที่ใช้ ray 14 ทิศ จึงเป็นค่าประมาณ ไม่ใช่การจำลองเสียงจริง

## ติดตั้ง
1. บีบอัดโฟลเดอร์ `behavior_pack` เป็น zip แล้วเปลี่ยนนามสกุลเป็น `.mcpack` (ไฟล์ `manifest.json` ต้องอยู่ชั้นบนสุดใน zip)
2. เปิดไฟล์ `.mcpack` ระบบจะ import เข้า Minecraft
3. สร้างหรือแก้โลก → Behavior Packs → เปิดใช้ Cave Echo Sounds

ใช้ Script API `@minecraft/server` 2.11.0 (stable) สำหรับเกม 1.26.6x
