# Cave Echo Sounds (Minecraft Bedrock Addon)

ทำให้เสียงก้องเมื่ออยู่ในถ้ำ โดยใช้เสียง vanilla เล่นซ้ำ 3 ครั้ง หน่วงเวลา และเบาลงเรื่อย ๆ จึงไม่ต้องมีไฟล์เสียงเพิ่ม

## เสียงที่ก้อง (เฉพาะในถ้ำ)
- ขุดหิน ตัดไม้ และทุบบล็อก (เสียงตามชนิดบล็อก เช่น หิน ไม้ ดิน ทราย deepslate)
- ผู้เล่นหรือ mob โดนตี (เสียงตีและเสียงร้องเจ็บของ mob นั้น)
- จุดไฟด้วยไฟแช็ก (flint and steel) หรือลูกไฟ (fire charge)

"ในถ้ำ" คือมีบล็อกทึบอย่างน้อย 4 บล็อกในแนว 32 บล็อกเหนือตำแหน่งนั้น ปรับได้ที่ `MIN_SOLID_ABOVE` และ `SCAN_HEIGHT` ใน `behavior_pack/scripts/main.js`

## ข้อจำกัดของเกม
- ไม่มี reverb จริง เป็นการเล่นเสียงซ้ำแบบหน่วงเวลา
- เสียงเดิมของเกมยังดังตามปกติ เสียงก้องจะซ้อนทับ
- เสียงที่ mob ร้องเองแบบสุ่มไม่ก้อง เพราะ Script API ดักเสียงนั้นไม่ได้ จะก้องเฉพาะตอนโดนตี
- ตรวจถ้ำแค่แนวตั้งเหนือตำแหน่ง ไม่ได้ดูรูปร่างถ้ำจริง ใต้ต้นไม้หนาหรือในบ้านหลายชั้นก็อาจนับเป็นถ้ำ

## ติดตั้ง
1. บีบอัดโฟลเดอร์ `behavior_pack` เป็น zip แล้วเปลี่ยนนามสกุลเป็น `.mcpack` (ไฟล์ `manifest.json` ต้องอยู่ชั้นบนสุดใน zip)
2. เปิดไฟล์ `.mcpack` ระบบจะ import เข้า Minecraft
3. สร้างหรือแก้โลก → Behavior Packs → เปิดใช้ Cave Echo Sounds

ใช้ Script API `@minecraft/server` 2.11.0 (stable) สำหรับเกม 1.26.6x
