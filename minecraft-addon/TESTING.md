# ทดสอบ Giant Anaconda Horror (Bedrock 1.21+)

## ติดตั้ง
1. เปิดไฟล์ `giant_anaconda_horror.mcaddon` (ดับเบิลคลิก/แชร์เข้า Minecraft)
2. สร้างโลกใหม่ → Behavior Packs + Resource Packs → เปิดทั้งสองแพ็ก
3. ตั้งค่า → Creator → เปิด **Content Log GUI** (เพื่อเห็น error)

## เช็กลิสต์
| # | ทำอะไร | ต้องเห็นอะไร |
|---|--------|-------------|
| 1 | `/summon horror:giant_anaconda` | งูดำยาว ~16 บล็อก เกล็ดมีเงานูน คิ้วหนาบังตา ฟันแหลมเรียงริมปาก หนามบนหลัง |
| 2 | `/time set midnight` ไปที่มืด | ตาเหลืองเรืองแสงชัด ฟันเรืองจางๆ (ส่วนอื่นมืด) |
| 3 | เดินเข้าไปใกล้ ≤ 20 บล็อก | งูหยุด **ชูคอขึ้น** หันมาจ้อง อ้าปากเล็กน้อย มีเสียงขู่ |
| 4 | รอ 5–9 วินาที | เสียงคำราม คอโน้มไปข้างหน้า **ขากรรไกรงับเป็นจังหวะ** แล้วไล่ล่า |
| 4b | สังเกตตอนงูอยู่เฉยๆ | แลบลิ้นสองแฉกทุก ~3 วินาที ลำตัวส่ายเป็นคลื่นตอนเลื้อย (เร็วขึ้นตามความเร็ววิ่ง) |
| 4c | ตอนงูจ้อง | คอส่ายซ้าย-ขวาช้าๆ แบบงูเห่า หัวเอียง ได้ยินเสียง **ขู่ฟ่อ** (เสียงใหม่ ไม่ใช่ Warden) |
| 4d | ให้งูกัด | ท่า **ฉก**: ง้างคอ → พุ่ง อ้าปากกว้าง → งับ พร้อมเสียงงับ |
| 4e | ตีงู | งูสะดุ้งหัวสะบัด + เสียงร้องเจ็บ |
| 4f | ฆ่างู | หัวฟุบ ปากอ้า ลำตัวขด + เสียงตาย |
| 4g | ยืนใกล้งูที่เลื้อย/อยู่เฉย | เสียงเกล็ดลากพื้น, เสียงหายใจครางต่ำเป็นระยะ |
| 5 | ตีงูตอนมันจ้อง | ไล่ล่าทันที |
| 6 | วิ่งหนีขึ้นผนัง/ซ่อนหลังใบไม้หรือกระจก | งูไต่ผนังตาม พังใบไม้/กระจก แต่ไม่พังหิน/ไม้ |
| 7 | ปล่อยให้งูฆ่า (Survival) | งูหายไปพร้อมเสียง |
| 8 | หนีพ้นระยะ | งูยังอยู่ ไม่หาย |
| 9 | ไข่เกิด `Giant Anaconda Spawn Egg` | ใช้เรียกงูได้ |

## ส่งผลกลับมา
บอกข้อที่ไม่ผ่าน + ข้อความใน Content Log (ถ่ายรูป/คัดลอก) + เวอร์ชันเกม
