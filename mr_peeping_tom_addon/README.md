# Mr. Peeping Tom: Minecraft Bedrock Add-on

สุภาพ อบอุ่น และจ้องมองคุณอยู่ตลอดเวลา

- รองรับเกม: Minecraft Bedrock **v26.6x** (`min_engine_version 1.26.60`)
- สคริปต์: `@minecraft/server` **2.11.0** (เวอร์ชันเสถียร) **ไม่ต้องเปิด Experiments และไม่ปิด Achievement**

## ติดตั้ง
1. เปิดไฟล์ `dist/MrPeepingTom.mcaddon` เกมจะ import ทั้ง Behavior Pack และ Resource Pack ให้อัตโนมัติ
2. สร้างโลกใหม่ หรือแก้ไขโลกเดิม แล้วเปิด **Behavior Pack: Mr. Peeping Tom (BP)** (Resource Pack จะถูกเปิดตามให้เอง)
3. เข้าเล่นได้เลย เขาจะเริ่มปรากฏหลังเข้าโลกประมาณ 1 นาที

## คำสั่งทดสอบ (ต้องเปิด Cheats)
| คำสั่ง | ผล |
|---|---|
| `/scriptevent ppt:wrath 8` | ตั้งค่า Wrath (0-12) ระดับ 1 = 0-3, ระดับ 2 = 4-7, ระดับ 3 = 8+ |
| `/scriptevent ppt:summon` | ให้เขาปรากฏทันที |
| `/scriptevent ppt:hunt` | บังคับให้เริ่มไล่ล่า |
| `/scriptevent ppt:scare` | ทดสอบ Jumpscare |
| `/scriptevent ppt:info` | ดู Wrath / ระดับ / สถานะ |
| `/scriptevent ppt:clear` | ไล่เขาออกไป 10 นาที |

ไข่เรียก (Spawn Egg) อยู่ในหมวด Spawn Eggs ของ Creative

## สิ่งที่ทำตามสเปก
- **อมตะ**: ไม่รับดาเมจใด ๆ ยกเว้นตกโลก (ใช้วิธีเดียวกับ Creaking ใน vanilla) ถ้าโดนตีครบจำนวนครั้งจะหมุนตัวสลายเป็นควันดำ พูดว่า *"Until next time, friend."* แล้วกลับมาพร้อม Wrath +2
- **ไม่เกิดใน The End** ทั้งการเกิดตามธรรมชาติและจากสคริปต์
- **กลางวัน**: เกิดห่างผู้เล่น 30-50 บล็อก หลบหลังสิ่งกีดขวาง เอนตัวแอบมอง และทักทายอย่างสุภาพ ถ้าเข้าใกล้เกิน 15 บล็อกหรือมองตรงไปที่เขา จะสลายเป็นควันแล้วไปโผล่ที่อื่น ไม่โจมตีเด็ดขาด
- **กลางคืน / Nether**: สะกดรอย และขยับเข้ามาใกล้ขึ้นทุกครั้งที่คุณหันหลัง จะโจมตีเฉพาะตอนคุณอ่อนแอ (HP ≤ 50%), อยู่คนเดียว, กำลังขุดหรือสู้กับมอนสเตอร์อื่น หรืออยู่ในที่มืด เมื่อตีโดนแล้วจะ jumpscare แล้วหายไปทันที ไม่ยืนสู้แบบตรง ๆ
- **Wrath 3 ระดับ**: ระดับ 1 อยู่ห่าง ๆ, ระดับ 2 เข้ามาใกล้ขึ้น ทุบประตูไม้ และเริ่มมีเสียงโดรนกดดัน, ระดับ 3 ทุบกระจก ปล่อย Darkness เป็นระยะ และซุ่มโจมตีจากเพดาน (กระซิบ *"Look up."* ก่อน)
- **Jumpscare**: ล็อกกล้องจ้องหน้าเขา 1.5 วินาที จอสั่น จอแดงแวบ เสียงกรีดร้องซ้อนกับเสียงหัวเราะเบา ๆ แบบอู้อี้ จากนั้นผู้เล่นติด Blindness และ Slowness
- **Environmental Interactions 11 อย่าง**: ป้ายข้อความ, หินกลายเป็นแร่ทอง/เพชรเป็นเหยื่อล่อ, ดับไฟในรัศมี 15 บล็อก, ใบไม้ไหวพร้อมเสียงกิ่งหัก, ฟองน้ำสีดำ, หมาขู่และแมวฟ่อ, รอยมือเขม่าบนกำแพง, เสียงเคาะ 3 ครั้ง, ประตูเปิดปิดเอง, รอยเท้าดำ และเข็มทิศ/นาฬิกาเพี้ยน
- **ท่าทาง 8 ท่า + 2 ท่าเสริม**: idle_twitch, peek_lean, stalk_walk, sprint_chase, crawl_one_block, wall_climb, swim, vanish และเพิ่ม scare (ตอน jumpscare) กับ look_at_target
- **เสียงพูด**: เสียงผู้ชายสุภาพและอบอุ่น สร้างด้วย ElevenLabs (เสียง "Jonah Vale") จำนวน 7 ท่อน

## สิ่งที่ต่างจากสเปก (บอกตรง ๆ)
1. **Hitbox**: ตอนปกติสูง 2.3 บล็อก ตอนไล่ล่าลดเหลือ 1.8 บล็อก (ท่าวิ่งโน้มตัวต่ำ) และตอนคลานลดเหลือ 0.85 บล็อก เพราะถ้าสูง 2.3 ตลอด ระบบหาเส้นทางจะเดินลอดประตูสูง 2 บล็อกไม่ได้เลย
2. **เข็มทิศ/นาฬิกาหมุนจริงทำไม่ได้** ไม่มี API ไหนควบคุมเข็มได้ จึงใช้ตัวอักษรเพี้ยนบนแถบ actionbar + เสียงติ๊ก + จอสั่นเบา ๆ แทน
3. **แมว "ไม่ยอมนั่ง" ทำไม่ได้** ทำได้แค่ให้แมวหันไปจ้องและฟ่อใส่ (หมาหันไปจ้องและขู่ได้ตามสเปก)
4. **โมเดล** สร้างจากลูกบาศก์ตามสไตล์ Minecraft (Blockbench format) อิงสัดส่วนจากภาพอ้างอิง จึงไม่ละเอียดเท่าภาพ 3D ต้นฉบับ
5. **เสียงร้อง/เคาะ/โดรน** สังเคราะห์ด้วยโค้ด เพราะ ElevenLabs connector ที่ใช้อยู่สร้างได้เฉพาะเสียงพูด ส่วนเสียงหัวใจเต้นใช้ของ Warden ใน vanilla
6. ค่าความเร็ว 0.18 / 0.34 ใช้ตามสเปก **ยังไม่ได้ปรับจูนในเกมจริง**

## ป้องกันการแลค
- คำนวณ AI ทุก 0.5 วินาทีต่อผู้เล่น (ไม่ใช่ทุก tick) และเรียก raycast สูงสุด 1 ครั้งต่อรอบ
- การสแกนหาประตู ไฟ และใบไม้ ใช้ `system.runJob` กระจายงานไปหลาย tick
- เหตุการณ์รอบตัวเกิดห่างกัน 12-45 วินาที และมี Mr. Peeping Tom ได้แค่ 1 ตัวต่อผู้เล่น
- ผลจำลอง 4 วันในเกม: เฉลี่ยอ่านบล็อก 0.9-1.7 ครั้งต่อ tick และไม่มี error

## แก้เสียง / แก้โมเดล
- ไฟล์เสียงอยู่ที่ `resource_packs/sounds/ppt/*.ogg` วางไฟล์ `.ogg` ชื่อเดิมทับได้เลย (ต้องเป็น mono ถ้าต้องการเสียงแบบ 3D)
- เสียงพูดต้นฉบับ (mp3) อยู่ที่ `tools/voice_src/` ส่วน effect (เสียงก้อง/อู้อี้) กำหนดไว้ใน `tools/build.py`
- สร้างไฟล์ใหม่: `python3 tools/build.py` (ต้องมี numpy, Pillow, ffmpeg) จะได้ `dist/MrPeepingTom.mcaddon`
- ดูตัวอย่างโมเดลและท่าทาง: `python3 tools/preview.py preview.png`
