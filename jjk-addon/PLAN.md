# JJK Addon — แผน (Toji mob + 5 อาวุธ)

สถานะ: **แผนเท่านั้น ยังไม่สร้าง** รอโควตารีเซ็ต

## เป้าหมาย
Minecraft Bedrock addon (Android, เกม v26.62 ตามภาพที่ผู้ใช้ส่ง) — mob โทจิ เกิดตามธรรมชาติ ถืออาวุธครบ แข็งแกร่งมาก AI เลือกอาวุธเอง ชื่อไอเทมภาษาไทย ลุคตามอนิเมะ

## ต้องเช็กก่อนเขียน (ยังไม่รู้)
- `format_version` และ `min_engine_version` ที่ตรงกับ v26.62
- เวอร์ชัน `@minecraft/server` ที่ตรงกับ v26.62 และต้องเปิด Beta APIs หรือไม่
- วิธีนำเข้า `.mcaddon` บน Android
ต้องอ่านเอกสารทางการ ห้ามเดา

## โครงสร้างแพ็ก
- `BP/` behavior pack: manifest, entities/toji, items (5 อาวุธ), spawn_rules, loot, scripts/main.js, animation_controllers
- `RP/` resource pack: manifest, models/entity/toji.geo.json, textures (วาดด้วยโค้ด สไตล์บล็อก), animations, sounds ref, particles, lang/th_TH.lang

## โทจิ
เสื้อดำแขนสั้น กางเกงขาว โซ่ที่ตัว หนอนม่วงพันตัว (ทำเป็นชิ้นบล็อก) ดาบพาดบ่า

## กฎเลือกอาวุธ (AI ใน script)
| อาวุธ | เงื่อนไข |
|---|---|
| ดาบฟันวิญญาณ | เป้าหมายเกราะ >= 10 แต้ม และอยู่ระยะใกล้ |
| หอกพลิกฟ้า (ไม่ต่อโซ่) | เป้าหมายเลือด < 10 หัวใจ และเกราะน้อย พุ่งจู่โจม โอกาสตายสูง |
| ปืน 9 มม. | ใช้ได้ทุกสถานการณ์ ระยะไม่เกิน 15 บล็อก โดนแล้วช้า 1 วินาที |
| ยูอุน (กระบองสามท่อน) | ถูกรุมตั้งแต่ 2 คน บล็อกดาเมจได้บางครั้ง |
| โซ่หมื่นลี้ | อยู่พื้นที่โล่ง แอนิเมชันต่อหอก+โซ่ เปิดช่องให้ผู้เล่นสวนกลับ ตีไกลสุด 30 บล็อก ช้ามาก หลังใช้แล้วแทบไม่สลับอาวุธ |

ค่าตัดเลือด/เกราะเป็นค่าที่ผมเสนอ ผู้ใช้อนุมัติแล้ว

## ต้องมีของประกอบ
แอนิเมชันสลับอาวุธ, เสียง, พาร์ติเคิล/เอฟเฟกต์ของโซ่และปืน (ใช้ของในเกมที่มี)

## ข้อจำกัด
- ทดสอบในเกมไม่ได้ ตรวจได้แค่โครงสร้าง/JSON/ไวยากรณ์
- texture/โมเดลเป็นบล็อก ไม่เหมือนภาพอ้างอิงเป๊ะ
- ผู้ใช้ต้องทดสอบในเกมแล้วส่งผล/ข้อผิดพลาดกลับมาแก้

## ขั้นตอนสร้าง (หลังรีเซ็ต)
1. เช็กเอกสารเวอร์ชัน -> manifest
2. โครง BP/RP + โทจิเปล่า
3. อาวุธทีละชิ้น
4. script AI เลือกอาวุธ
5. แอนิเมชัน/เสียง/เอฟเฟกต์
6. สคริปต์ตรวจ JSON + แพ็ก `.mcaddon`
