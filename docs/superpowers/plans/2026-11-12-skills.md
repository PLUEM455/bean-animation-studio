# Skills (Gojo 13 + Toji 13) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use `- [ ]`.

**Goal:** สกิลทั้ง 26 ตาม spec พร้อมท่าทาง เอฟเฟกต์ เสียง และ AI เลือกสกิลเอง — เสถียร ไม่ต้องเปิด Experimental

**Architecture:** Script API `@minecraft/server` **2.9.0** (stable; เกม 1.26.52 มี 2.11.0 เป็น beta → stable ≤ 2.10.0; เลือก 2.9.0 เผื่อระยะ). โค้ดแยก:
- `scripts/core/*` — ตรรกะบริสุทธิ์ ไม่แตะ API เกม (ทดสอบด้วย `node:test`): `vec.js`, `blockRules.js`, `brain.js` (เลือกสกิล), `rope.js` (verlet rope), `cooldowns.js`
- `scripts/game/*` — ตัวกลางเรียก API: `fx.js` (particle/sound/anim), `combat.js` (ดาเมจ, เป้าหมาย, ทำลายบล็อกตามกฎ), `tasks.js` (ตัวจัดลำดับงานหลาย tick)
- `scripts/mobs/gojo.js`, `scripts/mobs/toji.js` — สกิล
- `scripts/main.js` — loop ทุก 4 tick, before/after events
ตรวจชนิดด้วย `tsc --checkJs` กับ typings 2.9.0 (ยืนยันว่าเรียกเฉพาะ API ที่มีในเวอร์ชันนั้น)

**Spec:** gojo + toji design specs (สกิล, ดาเมจ, กฎบล็อก, Chain + Spear ข้อ 4)

## Global Constraints
- กฎบล็อก: ทำลายเฉพาะบล็อกที่มนุษย์สร้าง; ธรรมชาติ+ต้นไม้+พืช ห้ามทำลาย
- Chain + Spear: ไม่ดึงเข้าหาตัว, ไกลสุด 20, โซ่ฟิสิกส์ verlet, โหมดเล็ง/กวาด 360°
- ดาเมจตาม spec; Sorcerer Killer ×1.5
- ห้ามโจมตีผู้เล่นก่อน (เป้าหมาย = ผู้ที่ตีก่อน หรือ monster)
- ภาระ CPU: loop ทุก 4 tick, จำกัดจุด particle ต่อเฟรม, ทุก task มีเพดานเวลา

## Review Focus
1. API ที่ไม่มีใน 2.9.0 → สคริปต์ทั้งแพ็กไม่โหลด → `tsc` ต้องผ่าน
2. เรียก API แก้โลกใน before-event (read-only) → error → เลื่อนด้วย `system.run`
3. entity ตาย/หายกลาง task → ต้องเช็ก `isValid` ทุก tick ของ task
4. ทำลายบล็อกธรรมชาติโดยไม่ตั้งใจ → เทสต์ `blockRules` + ทุกการทำลายผ่าน `breakIfAllowed`
5. โซ่ยืดผิดความยาว/ดึงเป้า → เทสต์ `rope.js` (ความยาวข้อคงที่, ห้อยตามแรงโน้มถ่วง, ปลายถึงเป้าในเวลาที่เพิ่มตามระยะ)
