# JJK Addon — Mob: Satoru Gojo (Design Spec)

วันที่: 2026-11-12
แพลตฟอร์ม: Minecraft Bedrock Edition v26.52
ขอบเขตรอบนี้: **mob โกโจ + ไข่เสก เท่านั้น** (ไอเทมพลัง/อาวุธ = รอบถัดไป)

## 1. เป้าหมาย
สร้าง mob โกโจ ที่มีโมเดล 2.5D, อนิเมชันลื่น, เอฟเฟกต์และเสียงคุณภาพ (ห้ามทำลวก), และ AI ที่เลือกสกิลเองได้

## 2. การตัดสินใจที่ยืนยันแล้ว
| หัวข้อ | ค่า |
|---|---|
| ท่าทีต่อผู้เล่น | **เป็นกลาง** — ไม่สนผู้เล่น จนกว่าจะโดนตีก่อน แล้วสู้กลับเต็มที่; ไล่สู้ hostile mob เอง |
| การเกิด | จากไข่เสกเท่านั้น ไม่เกิดเองในโลก |
| เลือด | 500 + boss bar ขณะต่อสู้ |
| โมเดล | 2.5D = ทรงสกินผู้เล่น + ชิ้นนูน (ผมชี้ออก, เสื้อ/เข็มขัดมีความหนา) อิงสกินอ้างอิงที่ผู้ใช้ส่ง (ผมขาว, ตาฟ้า, เสื้อดำ, กางเกงเทา, เข็มขัดผ้ากรมท่า, รองเท้าดำ) |
| เสียง | ผสม: สังเคราะห์ด้วยโค้ดก่อน ผู้ใช้เปลี่ยนเป็นไฟล์ของตัวเองได้ภายหลัง (ชื่อไฟล์คงที่) |
| วิธีสร้าง | Script API (`@minecraft/server`) + animation controllers + custom particles; ตรวจเวอร์ชัน Script API ที่รองรับ v26.52 จากเอกสารทางการก่อนเขียนโค้ด |

## 3. กฎการทำลายบล็อก (ใช้กับทุกสกิลและทุก mob ใน addon)
- **ทำลายได้:** บล็อกที่มนุษย์สร้าง (ไม้แปรรูป อิฐ กระจก หีบ ฯลฯ รวมบ้านผู้เล่น)
- **ทำลายไม่ได้ (บล็อกธรรมชาติ):** ดิน, หญ้า, หินทุกชนิด, ทราย, กรวด, ดินเหนียว, แร่, น้ำ, ลาวา, Bedrock, หิมะ, น้ำแข็ง, Netherrack, End Stone, ท่อนไม้/ใบไม้, ดอกไม้/หญ้าสูง/เถาวัลย์
- ทำเป็นโมดูลเดียว (`naturalBlocks` + ฟังก์ชันตรวจ) ให้ทุกสกิลเรียกใช้

## 5. AI การตัดสินใจ
ประเมินทุกไม่กี่ tick: ระยะเป้าหมาย, จำนวนศัตรู, เลือดตัวเอง, คูลดาวน์
- ใกล้ → คอมโบ / Black Flash
- กลาง → Blue / Red / Blue Pull + Punch
- ไกล → Blink เข้าหา หรือ Hollow Purple
- ศัตรู ≥ 3 หรือเลือด < 40% → Domain Expansion
- เลือดต่ำมาก → Hollow Purple 200%
- ทุกสกิลมีคูลดาวน์ + สุ่มเล็กน้อยกันท่าซ้ำ
- เป้าหมาย: hostile mob ใกล้เคียง หรือผู้ที่โจมตีโกโจก่อน

## 6. อนิเมชัน (~15 ท่า)
ยืนนิ่ง, เดิน, วิ่ง, คอมโบ 1/2/3, Black Flash, ร่าย Blue, ร่าย Red, ชาร์จ Purple, ยิง Purple, ท่า Domain, Blink, โดนตี, ตาย — เปลี่ยนท่าด้วย blend transition ใน animation controller

## 7. เอฟเฟกต์และเสียง
- custom particle แยกต่อสกิล: ลูกแสงหมุน (Blue/Red), ลำแสงม่วง, ทรงกลมดาว (Domain), ประกายดำแดง (Black Flash), ตาเรือง, ออร่า RCT, วาร์ป
- เสียงแยกไฟล์ต่อสกิล ลงทะเบียนใน `sound_definitions.json`

## 8. ไข่เสก
ไอคอนเฉพาะ โทนขาว-ฟ้า-ดำ, ชื่อ "Satoru Gojo"

## 9. โครงสร้างไฟล์ (ร่าง)
```
jjk-addon/
  behavior_pack/   manifest.json, entities/gojo.json, scripts/ (main, ai, skills/*, blockRules)
  resource_pack/   manifest.json, entity/, models/entity/gojo.geo.json, textures/, animations/,
                   animation_controllers/, render_controllers/, particles/, sounds/, texts/
  build → JJK_Addon.mcaddon
```

## 10. ลำดับการสร้างและทดสอบ (ผู้ใช้ทดสอบในเกมทุกขั้นก่อนไปต่อ)
1. โมเดล + เท็กซ์เจอร์ + ไข่เสก
2. อนิเมชัน
3. AI + สกิลทีละกลุ่ม (ติดตัว → ประชิด → เทคนิค → ไม้ตาย)
4. เอฟเฟกต์และเสียง

## 11. ข้อจำกัด
- Claude เปิด Minecraft ไม่ได้: ตรวจได้เฉพาะความถูกต้องของ JSON / สคริปต์ — ความสวยงามต้องผู้ใช้ทดสอบ
- เสียงสังเคราะห์ไม่เหมือนอนิเมะ
- ตัวละครมีลิขสิทธิ์: ใช้ส่วนตัวได้ แจกจ่าย/ขายควรระวัง
