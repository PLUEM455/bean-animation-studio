# Real Darkness — Minecraft Bedrock Add-on (design)

Target: Minecraft Bedrock v26.62 (from user screenshot).

## Goal
- Day: unchanged.
- Night (overworld): as dark as the engine allows, using black distance fog that also hides the far view.
- Held light: holding a light item (torch, lantern, ...) lights the area around the player; light level = the item's vanilla light level.
- Sun/moon: brighter, nicer textures, no extra world light.
- Settings item: toggle fog, fog density (thin/medium/thick), toggle held light. Operators only. Settings are world-wide.

## Packs (shipped as one `.mcaddon`)
| Pack | Contents |
|---|---|
| `RealDarkness_BP` | script (`scripts/main.js`), settings item, crafting recipe |
| `RealDarkness_RP` | fog definitions, settings item texture, en_US/th_TH text |
| `RealDarkness_Sky_RP` | sun/moon textures (separate so it can be turned off in world settings) |

Sun/moon toggle in the menu: not possible — no script API swaps textures at runtime (searched; only Vibrant Visuals lighting/atmospherics are scriptable). Agreed fallback: separate resource pack.

## Night fog
- Every 20 ticks: read `world.getTimeOfDay()`.
  - 12000–13000 and 23000–24000 → `realdarkness:dusk`
  - 13000–23000 → `realdarkness:night_<density>`
  - otherwise → no fog
- Only in `minecraft:overworld`. Uses `player.fogSettings.push/remove` with tag `realdarkness`.
- Fog off in settings → our fog removed.

## Held light
- Every 2 ticks per player: main hand + off hand item; brightest known light level wins.
- Place `minecraft:light_block_<N>` (per-level ids since 1.21.20) at the player's head block if it is air; remove previous one when the player moves or stops holding the item.
- Never overwrite non-air blocks; only removes blocks it placed (still a light block of the same level).

## Settings item `realdarkness:settings`
- Recipe: 8 iron ingots around 1 coal (shaped `###/#C#/###`).
- Given once on first spawn (player dynamic property flag).
- Use → if `playerPermissionLevel >= Operator` show `ModalFormData`, else message "no permission".
- Stored in world dynamic properties.

## Revision 2 (2026-11-11)
- New darkness level **pitch** (fog end 8). Fog files generated by `tools/make_fogs.py`: 4 levels × 10 night profiles + `dusk` + `eclipse`.
- Night profiles from `world.getMoonPhase()`: new / crescent / quarter / gibbous / full. Full moon is rolled once per night: blood 10%, super 15%, micro 15%, honey 10%, blue 5% (no visible effect), else full; every 12th full moon = loykrathong. Solar eclipse: day after a new-moon night, 10%, time 5400–6600. No chat messages.
- Vibrant Visuals: `@minecraft/server-graphics` 1.0.0 `getBiomeLighting` for every biome — night ambient/moon illuminance and moon colour per profile; reset at day. Only visible with Vibrant Visuals on.
- Held light: light blocks at head + 4 points 4 blocks away (N/S/E/W). If any of them is removed by something else, the whole group goes out until the player swaps items. `/scriptevent realdarkness:extinguish` does the same for other add-ons.
- Textures: 32×32 gear item icon; 64×64 limb-darkened sun; 128 px per moon phase with sphere-lit terminator. True 3D sun/moon not possible (engine draws flat quads). Tides not implemented.

## Revision 3 (2026-11-11)
- Sun/moon textures merged into `RealDarkness_RP` (no separate sky pack). Transparent backgrounds; moon has no rim, unlit side see-through.
- Sun phenomena (silent): golden hour fog at 12000–13000 and 23000–24000; per day after a new-moon night: total eclipse 10% / annular eclipse 10% (staged fog ramp 5400–6600 + VV sun illuminance); otherwise halo day 10% (milky fog + VV sun mie 40) / haze day 10% (yellow fog + VV sun mie 25) between 1000–11000.
- Vibrant Visuals darkness scales with the darkness level (ambient and moon illuminance). With fog off + VV on, darkness comes from lighting, so placed lights stay visible far away. Not achievable in the normal renderer (fog is distance-only).
- Packs bumped to 1.2.0.

## Revision 4 (2026-11-12) — automatic fog
- Vibrant Visuals code removed (tested in game: no visible effect). Darkness level menu removed.
- Fog fully automatic, every second per player, moves one step at a time over 13 steps (6…96 blocks, then no fog):
  - sky visibility = sky brightness of the state (day 1, golden 0.6, halo 0.9, haze 0.5, eclipse stages, night by moon profile 0–0.5) × min(1, sky light at head / 12) — so caves are dark by day too.
  - light visibility = closeness of nearest light (1 − d/24) × (0.45 + 0.55 × min(1, count/8)); sources = placed light blocks (lava, fire, torches, …) in a 49×25×49 box + held light items of any player.
  - visibility = 1 − (1 − sky)(1 − light); ≥ 0.97 → no fog.
- Fog colour: black in caves (sky light < 5); otherwise tinted by special night/day (blood, honey, Loy Krathong, golden hour, halo, haze, eclipse). 8 tints × 13 steps generated by `tools/make_fogs.py`.
- Packs 1.3.0.

## Revision 5 (2026-11-12) — thicker, stable fog
- Scan box 25×13×25 (radius 12) instead of 49×25×49; each player updated once per second on its own tick slot; held light every 4 ticks.
- Darker sky values (full moon 0.2, new 0), light term `closeness^1.5 × (0.35 + 0.65 × count/10)`, step = `vis^1.3 × 12`.
- Smoothing: EMA 0.35 per update, max one step per update, dead zone 0.6 step.
- Packs 1.3.1.

## Revision 6 (2026-11-12) — light-only darkness
- Daylight (day states, sky light ≥ 12, not total-eclipse peak): no fog; golden hour / halo / haze / eclipse ramp show colour-only fog at 50 blocks.
- Night, caves, total-eclipse peak: width from light sources only. Each source gives c = (level − distance)/15; vis = best^1.3 × (0.6 + 0.4 × min(1, (Σc − best)/4)); step = vis^1.5 × 14 over [2 … 64] blocks. No light → 2 blocks. Moon/special nights only set the colour.
- Smoothing as before, but gaps > 4 steps move 2 steps per update.
- Held light back to a single light block at the head (no four-corner pattern).
- Packs 1.4.0.

## Revision 7 (2026-11-12)
- Fix: light-block list was built during early execution (BlockTypes unavailable) → empty → placed lights ignored. Now built lazily on first scan.
- Fog steps [4 … 64] (never closer than 4 blocks, so the ground stays visible when jumping); fog_start 35% for steps ≤ 8.
- Light response: vis = best^1.1 × (0.65 + 0.35 × amount); step = vis^1.2 × 14.
- Faster creep: EMA 0.6, up to 2 steps per second (3 when the gap is > 5).
- Packs 1.4.1.
