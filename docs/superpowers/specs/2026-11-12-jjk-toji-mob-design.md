# JJK Addon — Mob: Toji Fushiguro (Design Spec)

วันที่: 2026-11-12
แพลตฟอร์ม: Minecraft Bedrock Edition v26.52
ขอบเขต: mob Toji ครบทุกขั้น (โมเดล, อนิเมชัน, AI, สกิล, เอฟเฟกต์, เสียง) สร้างทีละขั้น
อ้างอิงกฎร่วม: `2026-11-12-jjk-gojo-addon-design.md` ข้อ 3 (กฎบล็อก), วิธีสร้าง (Script API), เสียงแบบผสม, คุณภาพห้ามทำลวก

## 1. การตัดสินใจที่ยืนยันแล้ว
| หัวข้อ | ค่า |
|---|---|
| entity id | `jjk:toji` |
| ท่าที | เป็นกลาง — ไม่สนผู้เล่นจนโดนตีก่อน แล้วสู้กลับเต็มที่; ไล่สู้ hostile mob เอง |
| การเกิด | จากไข่เสกเท่านั้น |
| เลือด | 400 + boss bar ขณะต่อสู้ |
| อาวุธ | เป็นโมเดลที่ Toji ถือ (bone ในโมเดลของเขา) ไม่ใช่ไอเทมของผู้เล่น |
| กฎบล็อก | เหมือนโกโจ: ทำลายได้เฉพาะบล็อกที่มนุษย์สร้าง (ใช้โมดูลกฎบล็อกร่วม) |

## 2. โมเดล 2.5D (อิงสกินอ้างอิงที่ผู้ใช้ส่ง)
ทรงสกินผู้เล่น + ชิ้นนูน: ผมดำยุ่งเป็นปอย, ตาดำมีเงา, แผลเป็นมุมปาก, เสื้อดำรัดรูป (ชั้นหนา), **คำสาปหนอนสีม่วงพันเฉียงรอบลำตัว** (แบ่งข้อ 2.5D, หัวหนอนมีปากเพื่อคายอาวุธ), กางเกงขาวทรงหลวม, เข็มขัดผ้าดำผูกปม, รองเท้าดำ
อาวุธ (โมเดลแยก bone ซ่อน/แสดงได้): Split Soul Katana, Playful Cloud, Inverted Spear of Heaven, ข้อโซ่ Chain of a Thousand Miles, ปืนพก

## 4. Chain + Spear (รายละเอียด)
- **ห้ามดึงอะไรเข้าหาตัว** — เป็นการโจมตีระยะไกลล้วน
- ระยะไกลสุด **20 บล็อก**; ความยาวโซ่ = ระยะถึงเป้า; ยิ่งไกล อนิเมชันการโจมตีแต่ละครั้งยิ่งนาน
- **โหมดเล็ง** (ศัตรูตัวเดียว): ฟาดเป้าได้ทุกทิศ ทั้งบน/ล่าง/รอบตัว — 12
- **โหมดกวาด 360°** (ถูกล้อม): เหวี่ยงเป็นวงรอบตัว โดนทุกตัวในรัศมีความยาวโซ่ — 12/ตัว
- **ฟิสิกส์จริง:** จำลองเป็น verlet rope (ข้อต่อหลายข้อ) ใน Script API ทุก tick — แรงโน้มถ่วง (โซ่ห้อย), แรงเฉื่อย (เหวี่ยงเป็นโค้ง), หอกปลายโซ่มีมวล; วาดด้วยโมเดลข้อโซ่; จำกัดจำนวนข้อเพื่อไม่ให้เกมกระตุก

## 5. AI
- ใกล้ → Katana / Playful Cloud / หมัด; เป้าหันหลัง → Backstab
- กลาง → Chain + Spear (เล็ง); ถูกล้อม → Chain + Spear (กวาด 360°)
- ไกล → ปืน หรือ Speed Blitz เข้าหา
- เป้าเป็นผู้ใช้คำสาป (เช่น `jjk:gojo`) → เลือก Inverted Spear ก่อน
- เลือด < 40% → Sorcerer Killer Mode
- คูลดาวน์ทุกสกิล + สุ่มเล็กน้อย

## 6. อนิเมชัน / เอฟเฟกต์ / เสียง
- ท่า: ยืน, เดิน, วิ่ง (ก้มตัวแบบนักล่า), หมัดคอมโบ, ฟัน Katana, คอมโบกระบอง + ฟาดพื้น, แทงหอก, เหวี่ยงโซ่ (เล็ง/กวาด), ยิงปืน, Speed Blitz, หนอนคายอาวุธ, โดนตี, ตาย
- เอฟเฟกต์: ภาพติดตา, รอยฟันดาบ, ฝุ่น/แรงกระแทกฟาดพื้น, ประกายหอกลบล้างคำสาป, ปลอกกระสุน, ออร่าแดงช่วง Sorcerer Killer Mode
- เสียง: สังเคราะห์ก่อน เปลี่ยนเป็นไฟล์ผู้ใช้ได้ภายหลัง

## 7. ไข่เสก
ไอคอนเฉพาะ โทนดำ-ม่วง-ขาว (ผม, หนอน, กางเกง), ชื่อ "Toji Fushiguro"

## 8. ลำดับการสร้าง (ผู้ใช้ทดสอบทุกขั้น)
1. โมเดล + อาวุธ + เท็กซ์เจอร์ + ไข่เสก
2. อนิเมชัน
3. AI + สกิลทีละกลุ่ม (ติดตัว → ประชิด → Chain + Spear → ระยะไกล → ไม้ตาย)
4. เอฟเฟกต์และเสียง

## 9. ข้อจำกัด
- ทดสอบความสวยงาม/ฟิสิกส์ในเกมได้เฉพาะผู้ใช้
- ฟิสิกส์โซ่ถูกจำกัดจำนวนข้อเพื่อประสิทธิภาพ
- ตัวละครมีลิขสิทธิ์: ใช้ส่วนตัวได้ แจกจ่าย/ขายควรระวัง
