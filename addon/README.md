# Veincapitator (Minecraft Bedrock Add-on)

ย่อตัวแล้วขุดแร่ทั้งเส้นหรือตัดไม้ทั้งต้นในครั้งเดียว

## วิธีใช้

**ต้องกดย่อตัว (sneak) ค้างไว้ตอนขุด/ตัด** ถึงจะทำงานแบบรวมทั้งเส้น ถ้าไม่ย่อ จะขุดบล็อกเดียวตามปกติ

- **ขุดแร่ทั้งเส้น:** ใช้เหมืองหินขุดแร่ (`*_ore`, `ancient_debris`) แร่ชนิดเดียวกันที่ต่อกันจะถูกขุดตามทั้งหมด
- **ตัดไม้ทั้งต้น:** ใช้ขวานตัดท่อนไม้ (`*_log`, `*_stem`) ท่อนที่ต่อกันทั้งต้นจะถูกตัดตาม รวมถึงกิ่งเฉียง
- **ความทนทาน:** ขุด/ตัดรวมกินความทนทานเท่าขุด 1 บล็อกเท่านั้น

## คำสั่งในแชท

| คำสั่ง | ความหมาย |
|---|---|
| `!vein on` / `!vein off` | เปิด/ปิดการทำงาน |
| `!vein limit <1-256>` | จำนวนบล็อกสูงสุดต่อครั้ง (ค่าเริ่มต้น 64) |
| `!vein status` | ดูการตั้งค่าปัจจุบัน |

## การติดตั้ง

1. คัดลอกโฟลเดอร์ `Veincapitator_BP` ไปไว้ใน behavior packs ของโลกที่ต้องการ (หรือ zip เป็น `.mcpack`)
2. เปิดโลกนั้น แล้วเปิด Behavior Pack นี้ในหน้า Global Resources
3. เปิด **Beta APIs** / Script API ให้โลกนั้นใช้งานได้ (ดูการตั้งค่าโลก)

## ข้อจำกัดที่ควรรู้

- ยังไม่ได้ทดสอบในเกมจริง: ตรวจแล้วเฉพาะ logic หลัก (`tests/`) ส่วนที่เรียก Script API ต้องทดสอบในเกม
- `@minecraft/server` ในไฟล์ `manifest.json` ตั้งเป็น `1.13.0` และ `min_engine_version` เป็น `1.21.0` ต้องตรวจให้ตรงกับเวอร์ชันเกมที่ใช้
- บล็อกที่ขุดเพิ่มใช้ `setblock ... destroy` จึงไม่มีผลจาก Fortune / Silk Touch
